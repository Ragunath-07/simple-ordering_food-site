# Madras Kitchen

A simple food website built using HTML and CSS.
This project showcases a few popular South Indian dishes like Chicken Biryani, Mutton Biryani, Parotta, and Prawn Biryani.

## Tech Stack

CSS3 – styling

Created as a simple static website to showcase my work and practice front-end development.
